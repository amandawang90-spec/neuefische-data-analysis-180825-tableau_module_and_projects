# Tableau Data Analyst Mock Exam – Pre-Exam Checklist

Use this list to ensure you're fully prepared before taking the mock exam.

---

## Data & Setup

- [ ] I can **connect to a PostgreSQL database** (e.g., AWS server or local DB).
- [ ] I know how to work with **Live vs Extract** connections.
- [ ] I understand how to use the **Data Interpreter** and clean up imported files.
- [ ] I can create **folders, groups, joins, and unions** in Tableau.

---

## Core Tableau Features

- [ ] I can create and format **calculated fields**.
- [ ] I know how to apply **filters**, **parameters**, and use **filter actions**.
- [ ] I can build **maps** and **geographic visualizations**.
- [ ] I understand how to use **Groups**, **Sets**, and **Hierarchies**.
- [ ] I’ve practiced **Level of Detail (LOD) expressions** (FIXED, INCLUDE, EXCLUDE).
- [ ] I can build **dashboards** and add **interactivity** (actions, filters, highlights).
- [ ] I can use **Tableau Story** for presenting data narratives.

---

## Conceptual Knowledge

- [ ] I understand key Tableau terms: **dimensions, measures, aggregation**.
- [ ] I can distinguish between **KPIs and metrics**.
- [ ] I know how to interpret **dashboard requirements based on business questions**.
- [ ] I’ve reviewed the **types of charts** and know when to use each.
- [ ] I understand **data types, nulls, duplicates, and common data quality issues**.

---

## Practice & Review

- [ ] I’ve practiced with **at least one full dataset** (e.g., Flights/Airports/Weather).
- [ ] I’ve recreated dashboards from the SQL API project in Tableau.
- [ ] I’ve reviewed **exam structure and sample questions**.
- [ ] I’ve explored Tableau Public and familiarized myself with good visual design.

---

## 🚀 Final Prep(this part is before the real exam)

- [ ] I’ve attended the **mock exam session**.
- [ ] I’ve set up my environment with **Tableau Desktop** and a **reliable internet connection**.
- [ ] I’ve blocked **quiet, uninterrupted time** for the mock exam.


---

Good luck — remember, the mock exam is a **practice space**, not a test of perfection. Use it to identify areas to review and build confidence before the real thing!
