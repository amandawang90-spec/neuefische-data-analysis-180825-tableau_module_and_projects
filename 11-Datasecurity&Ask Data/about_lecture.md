# What we'll do in today's session
## Viz Extensions
- Get introduced to **Viz Extensions** in Tableau and how they can expand your dashboard capabilities beyond built-in charts.
- Learn how to install and use a **Sankey Diagram** extension step by step using Tableau Extensions.
- Understand when and why you might use extensions, and how they’re integrated securely into Tableau dashboards.

---

## Data Security & Permissions

- Explore what **data security** means in Tableau: who sees what, and how access is managed.
- Understand key concepts like **row-level security**, **user filters**, and **permissions**.
- Learn how to apply restrictions so different users see only the data relevant to them.
- This section prepares you for managing real-world dashboards used by multiple teams or clients.

---

## Ask Data & Natural Language Queries

- Discover **Ask Data**, Tableau’s built-in natural language query tool that helps users build charts by simply typing a question.
- Learn how to open Ask Data and explore a dataset using plain English (e.g., “Show sales by region last year”).
- Understand the strengths and limitations of natural language interfaces in analytics tools.

---

After exploring Sankey diagrams in the first part, you’ll dive into permissions and data security through hands-on exercises. You’ll also try out Ask Data to practice querying without dragging any fields at all.
