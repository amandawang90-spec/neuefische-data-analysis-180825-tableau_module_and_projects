# What we'll do in today's session

## Multiple data sources

- Understand how Tableau works with **multiple data sources** and when to use **joins, relationships,** and **blending**.
- Learn the key differences between these methods and why each one matters depending on your data model.
- Practice working with relationships between tables inside Tableau’s data model interface.
- Explore Tableau’s documentation to strengthen your understanding of how related data sources behave.
- please check the presentation for recap later


## Customizing Tableau

- Learn how to **customize color palettes** in Tableau by editing the `Preferences.tps` file.
- Understand the value of consistent color choices for branding and visual storytelling.
- Add a custom color palette to use in your dashboards, and test it inside your existing workbooks.
- Learn how to **create and assign custom icons** using Tableau’s **Shapes** feature.


## Animations in Tableau

- Build an animated line chart to show sales trends over time by category.
- Enable and configure animations in Tableau to see how user interaction can enhance storytelling.
- Use filters and observe how transitions change based on your settings.
- Compare different animation styles and when each might be more effective.

Hands-on practice will follow, and you’ll explore these customization features in your own dashboards.
