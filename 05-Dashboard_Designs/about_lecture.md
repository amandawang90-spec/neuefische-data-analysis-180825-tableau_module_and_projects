# What we'll do in today's session:

- Build on the workbook from previous days and focus on **dashboard design best practices** in Tableau.
- Learn how to create and style a dashboard with a clear, consistent layout and interactive features.
- Explore different ways to add **filters** in dashboards, including adding existing filters, adding filters directly from visualizations, and using a visualization itself as a filter.
- Practice adding **URL actions** to link dashboards to external web pages.
- Understand key principles of dashboard design: clarity, user-centered design, accessibility, performance, and security.


-----
Remember to apply hands-on practice during exercises to reinforce these skills!
